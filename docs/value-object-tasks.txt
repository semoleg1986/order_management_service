Шаг 1. Что такое Value Object (очень просто) (done)

Value Object — это объект, который:
	1.	Не имеет собственной идентичности
	2.	Определяется только своими значениями
	3.	Не живёт отдельно от владельца

Примеры в жизни:
	•	Деньги (100₽ = 100₽)
	•	Адрес
	•	Строка «товар × количество × цена»

Шаг 2. Почему OrderItem — это Value Object (done)

Ответим логически:
	•	Есть ли у OrderItem свой ID? → ❌ нет
	•	Важен ли он сам по себе? → ❌ нет
	•	Может ли он существовать без заказа? → ❌ нет

➡️ Значит OrderItem = Value Object

На человеческом языке:

	•	price — цена за единицу на момент заказа

Шаг 4. Пишем Value Object (без логики пока) (done)

from uuid import UUID
from decimal import Decimal

class OrderItem:
    """
    ValueObject OrderItem
    •	нет сеттеров
	•	нет анемичной модели
	•	нет логики в сервисах
    """
    __slots__ = ('_product_id', '_quantity', '_price')

    def __init__(self, product_id: UUID, quantity: int, price: Decimal | str | float) -> None:
        if quantity <= 0:
            raise ValueError("Quantity must be greater than zero")

        normalized_price = Decimal(str(price))

        if normalized_price <= Decimal("0"):
            raise ValueError("Price must be greater than zero")

        self._product_id = product_id
        self._quantity = quantity
        self._price = normalized_price

    @property
    def product_id(self) -> UUID:
        return self._product_id

    @property
    def quantity(self) -> int:
        return self._quantity

    @property
    def price(self) -> Decimal:
        return self._price

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, OrderItem):
            return False
        return (
            self.product_id == other.product_id
            and self.quantity == other.quantity
            and self.price == other.price
        )

    def __repr__(self) -> str:
        return (f"OrderItem({self.product_id!r}, "
                f"qty={self.quantity}, "
                f"price={self.price})")

    def __str__(self) -> str:
        return (f"OrderItem({self.product_id}, "
                f"qty={self.quantity}, "
                f"price={self.price})")

    def __hash__(self) -> int:
        return hash((self.product_id, self.quantity, self.price))

            quantity: int,
            price: Decimal | str | float

            raise ValueError("Cannot modify confirmed or cancelled order")

        for i, item in enumerate(self._items):
            if item.product_id == product_id and item.price == normalized_price:
                new_item = OrderItem(
                    product_id=product_id,
                    quantity=item.quantity + quantity,
                    price=normalized_price
                )
                self._items[i] = new_item
                self._touch()
                return new_item

        new_item = OrderItem(
            product_id=product_id,
            quantity=quantity,
            price=normalized_price
        )

        self._items.append(new_item)
        self._touch()
        return new_item
